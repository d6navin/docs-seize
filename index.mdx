Whether you run a small community or a large guild, seize gives you the tools to keep things organized and engaging without juggling multiple bots.

## Get started in 3 steps

<Steps>
  <Step title="Invite the bot">
    [Add seize to your Discord server](https://discord.com/oauth2/authorize?client_id=1550954284659638363&scope=bot+applications.commands&permissions=8). Grant Administrator permissions for full feature access. Need help? Join the [support server](https://discord.gg/seizeapp).
  </Step>
  <Step title="Set a prefix">
    Type `,prefix` to see the current prefix. Use `,prefix set <char>` to change it, or keep the default comma.
  </Step>
  <Step title="Explore commands">
    Type `,help` to browse commands by category, or jump into moderation, music, utilities, and more.
  </Step>
</Steps>

<Tip>
  You can also mention the bot (@seize) instead of using a prefix, or set a personal prefix with `,selfprefix set` if you have Premium.
</Tip>
